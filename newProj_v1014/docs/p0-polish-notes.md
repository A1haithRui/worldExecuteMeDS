## 延续到下一段的规则

- 深海底、青色路径、海沫白确认点沿用项目色彩；没有错误红。白色皮肤与衣服不被解释为远端赋予身份。人物始终保持原图五官、单枚鲸饰、鳍、长发与服装，未露出v4 body层的遮挡缺口。
- 对话/界面采用 Inter，歌词采用 Source Serif 4 的600字重，系统小标采用 JetBrains Mono。正文56px、强调80px；在允许行宽内自动换行，必要时减字号而不裁掉第三行。字幕从本机JSON取文，以句为单位保持可读；入场只有9px的短移动，不做逐字裁切或逐词卡拉OK。上字幕带和消息内字幕取代常驻大底栏。
- 连接点和路径共享几何数据；每个转场有被继承的点或空间关系。人物越近，辅助信息越少。纹理固定种子，动画仅取歌曲时间，禁止累计粒子、实时随机或依赖CSS自行播放。
- 相邻姿态仍优先整体推进与遮挡。掌心没有翻掌或屈指；角色背景渐退不等于让手层离开身体。在这里制作的是一次静态手势中的镜头靠近。

## 可重复导出

在主项目目录：

```powershell
npm run check:p0
npm run export:p0
```

导出入口 `tools/export-p0.mjs` 自动启动临时本地服务，使用已安装的Chrome（或Edge）离线绘帧。依赖先从本项目读取，再只读复用相邻Claude工程现有的 `playwright-core` / `ffmpeg-static`。独立环境可在本项目执行 `npm install`；这些是开发导出依赖，浏览器播放不需要它们。可用 `MV_DEPENDENCIES` 指向其他已安装依赖的项目，`MV_CHROME` / `MV_FFMPEG` 指向自选程序。

资源入口为 `window.readyPromise` / `window.renderReady`；失败有 `window.renderError`。导出逐帧调用 `window.renderFrame(songTime)`，与预览共用 `renderP0`；仅取Canvas的1920×1080 PNG后送入H.264编码，不录制播放器或浏览器边框。`?render=1`提供无控件舞台布局。图片、三套字体与本机歌词全部就绪之前只显示准备状态；P0内旧DOM显式隐藏。

原WAV解码后按44.1kHz采样切出 `[2611734,3265385)`，共653651采样，音频约14.822018秒；与精确59.223秒起点相比，采样四舍五入误差约−0.0068毫秒。不做音频流复制、不加入提示音、不更换音轨零点。

视频890帧，帧时间 `59.223 + i/60`；最后一帧取74.039667秒，仍在目标区间内。容器视频时长14.833333秒，比14.822秒请求区间长11.333毫秒，仅为不足一帧的尾帧保持。编码 H.264 High / CRF18 / yuv420p / BT.709，AAC-LC约256kbps、44.1kHz双声道。

媒体复核需要Python与NumPy，本机可运行：

```powershell
& 'C:/Users/28291/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' tools/check-p0-media.py
```

默认使用相邻参考工程中的ffmpeg，可通过 `--ffmpeg` 指定别处。输出视频、关键帧、解码帧与报告均在Git忽略的 `out/`；没有把本机歌词写入导出脚本或说明。
