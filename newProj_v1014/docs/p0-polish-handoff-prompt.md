## 4. 叙事与视觉方向

全曲故事是“触点—回声—失联”。这段是第一次亲近：本端接到远端回应，反馈形成关系，她尝试伸手，出现一次真实的接触，并将接触保存为内部路径。远端没有具象的人物身体，不要另造一名人类角色。

延续深海蓝、青色、海沫白：

- 深海底 `#06131F`，面板 `#0B2433`。
- 本端青 `#25BDD4`，激活青 `#83E9E6`。
- 远端确认与关键文字 `#E6F2EF`。
- 辅助灰蓝 `#526C7C`。

可以在这组颜色内调整明度与材质。此段不引入故障红。她的白色服装和皮肤原本就存在，不把“白色”解释为用户赐予身份。

每镜一个视觉中心。聊天界面、模型内部、角色版画轮流承担主画面。角色靠近时减少背景信息；网格、声呐、光点必须对应事件，避免成为常驻壁纸。建立有节制的前中后景、遮挡、细微纹理、留白与明暗层级。避免用大面积泛光遮住素材细节。

角色保持 v3 的脸、鲸鱼发饰、侧鳍、发型、水手领和尾巴。可使用整体推拉、平移、局部光影及谨慎的分层位移，不用二维拉伸伪造大幅转头或关节运动。
