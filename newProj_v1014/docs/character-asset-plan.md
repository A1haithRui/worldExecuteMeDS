# 角色素材与分镜需求

本项目不以“与 Claude 版文件数量相同”为目标。Claude 版的八张图包括四张主角基础姿态和四张特定歌词桥段的变体；新项目先按实际分镜决定是否制作变体。

| Claude 版素材 | 原版用途 | 当前 DeepSeek 素材或决定 |
| --- | --- | --- |
| `f_bust` | 主角正面基准、剪影与配准中心 | `deepseek_bust_v3.png`；已具备 |
| `f_profile` | 低头侧身、离线与孤独镜头 | `deepseek_profile_v3.png`；已具备 |
| `f_reach` | 伸手、手心互动与特写 | `deepseek_reach_v3.png`；已具备；大幅手部特写仍需检查清晰度 |
| `f_eye` | 单眼睁开的情绪近景 | `deepseek_eye_v3.png`；已具备 |
| `boy_bust` | 第二段预副歌的性别形态切换 | 待分镜确定：若保留这一桥段，设计同一角色的另一种形态，发饰、配色与衣领保持连续 |
| `man_bust` | 性别形态切换时短暂的淡重影 | 先尝试用另一形态的剪影、缩放和透明度程序生成；镜头审阅后再决定是否另绘 |
| `cat_bust` | 虎斑猫歌词段落的猫耳过渡 | 待分镜确定：可设计“鲸鱼娘短暂猫化”的过渡图，不必引入新角色 |
| `cat_paws` | 同一猫化段落的双手猫爪动作 | 若保留猫化桥段，应与猫耳过渡图作为一组制作 |

## 制作优先级

1. 先完成全曲镜头表，明确哪些歌词段落沿用或重写 Claude 版的视觉比喻。
2. 优先补会直接影响主角连续性的素材：正面无表情／低亮度剪影、独立手部近景，以及 v3 发饰在大特写里的稳定形状。这些不一定需要整张新立绘。
3. 如果保留性别切换和猫化桥段，再补另一形态正面、猫耳过渡和猫爪动作三张图；成年重影可先用程序实现。
4. 每张新图与 v3 主角核对发饰、鲸鳍、鲸尾、领口、色阶与透明边距，并记录关键部位位置，供后续动画和裁切使用。

若改用 Claude 版的原始场景引擎，除了图片，还必须重新测量角色关键点与配准参数，并调整原版按橙／米白／黑三色分版的逻辑；仅把文件名一一替换无法得到正确画面。当前独立浏览器样片直接显示 v3 PNG，不依赖该分版引擎。

已实际检查四张现用 v3。本轮没有新增生图，也没有以文件数量为目标制作变体。增补文件与镜头方案见 [v4 使用说明](../assets/character/v4/README.md)。

- 正面低亮与纯剪影已由 v3 调色得到，与原图同画布、同 Alpha 配准，可用于 MV。
- 伸手图已提取独立手层、人物底层与透明手部近景，原生手部内容 501×476px。已检查 1080p 画面中约 650px 宽的互动构图；全屏极近特写、新手势、翻掌或大幅手臂运动仍需按分镜判断局部补绘。人物底层的手后遮挡区尚未补画。
- 性别形态、猫耳过渡、猫爪动作的 DeepSeek 视觉方案和歌词候选窗口已记录，均未生成，等待全曲分镜。成年淡重影优先由另一形态的缩放、剪影与透明度实现。
- 四张 v3 原件及现有浏览器素材引用保持不变。v4 保存来源快照、来源哈希、处理参数、既有提示词来源与关键部位定位，供后续接入。
