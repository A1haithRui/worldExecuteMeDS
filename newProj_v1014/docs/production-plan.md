# DeepSeek 版 MV 制作路线（2026-10-15 草案）

## 已有基础

- 可在浏览器播放的独立样片，音频与本机歌词时间线已接通，支持跳转。
- v3 四张主角基础姿态：正面、侧身、伸手、眼部近景。
- v4 五个可复用素材：正面低亮图、纯剪影、独立手层、人物底层、手心近景。详见[角色 v4 说明](../assets/character/v4/README.md)。

这套素材足以制作全曲的粗分镜和数个正式镜头。尚不把猫化、另一性别形态、全屏手心或发饰近景视为已解决；这些镜头确定后再补画。

## 核心视觉关系

整支片是一场“你”和深海中的智能体逐渐接通、靠近、失联、再留下回声的对话。三个画面层各有用途：

1. **聊天界面**承载对话、状态和人与智能体之间的距离，取 DeepSeek Harness 的节奏与布局线索，重新设计为本片界面。
2. **模型内部**使用 TUI 字符、网格、声呐、节点和代码轨迹表达推理与世界构建；元素随歌词和音频变化，不作为常驻花纹。
3. **角色版画**承担情绪高潮、伸手互动和静默镜头。鲸鱼发饰、侧鳍、尾巴与水手领保持连贯；角色出现越近，画面越简洁。

基础色为深海蓝、亮青与海沫白。故障段落可短暂引入警示红；回到平静时收回红色。画面避免同时塞满聊天窗、TUI、歌词大字和完整角色，每镜头指定一个主角。

## 全曲粗结构

下表是镜头设计范围，不是最终切点；精确切点将以本机音频、歌词时间和节拍检查后写入镜头表。

| 歌曲时间 | 情绪与主画面 | 当前素材与待定内容 |
| --- | --- | --- |
| 0–29 秒 | 深海信号接入；界面逐步点亮，剪影变成正面角色 | v4 剪影／低亮、v3 正面；现有样片可作为起点 |
| 29–59 秒 | 对话建立；聊天窗与模型内部交替，歌词变成可见的几何关系 | v3 正面／侧身；补可复用的字符与节点动画 |
| 59–89 秒 | 第一次亲近和赠予；伸手、掌心触点，几个“如果”的视觉变换 | v3 伸手、v4 手层／手心；81–85 秒暂定保留短促猫化，先以分镜验证 |
| 89–119 秒 | 自我形态与在线状态变化；角色逐渐得不到回应 | 88–92 秒暂定保留形态切换；另一形态须等镜头构图锁定后绘制。随后用侧身、低亮和空聊天窗 |
| 119–148 秒 | 失联、删除、越界与错误扩散 | 眼部近景、低亮／剪影、界面状态；故障色只在关键拍出现 |
| 148–177 秒 | 代码循环与情绪高潮；前文图形以更紧的节奏回归 | 手部、眼部和正面角色；优先靠排版、配准错位与程序动画提高强度 |
| 177 秒–结束 | 回看、收束、关机；最后留下独立的回声 | 侧身、低亮、剪影；末镜给角色与字幕留静止空间 |

## 接下来的工作顺序

1. **全曲镜头表**：为每个约 8～16 秒的段落写明起止时间、歌词索引、主要画面、角色姿态、交互事件、所需素材和转场。先求故事连贯，暂不逐帧抠动画。
2. **低成本动态草片**：用当前浏览器工程把镜头表走通。每镜只放布局块、现有角色图和占位图形，检查 3 分 32 秒是否有空白、重复或叙事跳步。
3. **重点片段试做**：优先完成 59–95 秒。这一段同时验证聊天与版画切换、掌心互动、猫化和形态切换；能最早暴露真正缺少的角色素材。
4. **按已锁定镜头补画**：只给试做片段确认要展示的猫耳／猫爪或另一形态制作新素材，先完成跨姿态一致性与画布定位，再继续全曲。
5. **逐段精修与导出**：预览和导出共享同一条以歌曲秒数为输入的时间线。先出 1080p 小段校验音画、边缘和字幕，再做全片导出。

## 技术约束

- 最终画面以 1920×1080、16:9 构图；所有转场和角色运动应由歌曲时间决定，暂停、拖动与逐帧导出必须得到同一帧。当前样片里的 CSS 过渡只是概念效果，进入正式镜头时要替换成时间驱动动画。
- 本机音频与歌词正文继续留在 Git 之外；镜头表只记录时间和歌词索引，不复制歌词文本。
- 保留两份参考项目的来源及许可说明。DeepSeek 主题角色与界面为社区二创，不暗示官方合作。
- 每次新增角色图都保存来源、透明通道、关键点与可用放大范围；v4 底层的手部遮挡缺口在需要大幅手臂运动前必须补画。

## 第一阶段完成标准

全曲镜头表覆盖歌曲 0–约 212 秒；每个镜头都有清楚的主画面和素材状态。动态草片从头到尾可播放、可任意跳转，字幕与音乐保持对齐。59–95 秒重点片段的预览能判断是否真的需要三类待定新素材。
