# P0 本地字体

从本机参考工程已安装的 `@fontsource` 包复制以下拉丁子集，服务于离线可重复渲染，没有引用远程字体服务：

| 文件 | 上游包 | 用途 |
| --- | --- | --- |
| source-serif-4-latin-600-normal.woff2 | @fontsource/source-serif-4 | 歌词句级排版，600字重 |
| inter-latin-400-normal.woff2 | @fontsource/inter | 对话界面与短标签，400字重 |
| jetbrains-mono-latin-400-normal.woff2 | @fontsource/jetbrains-mono | 系统小字，400字重 |

三者按各自 SIL Open Font License 1.1 分发，完整许可见同目录 `source-serif-4-LICENSE`、`inter-LICENSE`、`jetbrains-mono-LICENSE`，保留原版权声明。字体未修改；“MV Serif / MV Sans / MV Mono”仅为本地CSS内部别名，不对外重命名字体产品。
