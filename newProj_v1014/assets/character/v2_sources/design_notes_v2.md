# 鲸鱼娘 v2 — 深海领航

本套为独立社区二创 MV 角色素材，不表示 DeepSeek 官方制作、合作或授权。

## 对 v1 的实际观察

四张图都保留青蓝长发、卷起呆毛、侧鳍、海军蓝服装与浅色水手领。正面脸部近乎全深色，侧面与伸手却有浅色脸部，眼部特写又有清晰眼睛；需要规定普通镜头也能露出一只眼睛。各姿态的发束与白色衣服折线、肩部波纹、挂环数量及方向会变化。侧鳍内缘的羽状分瓣存在视觉歧义。原图多处头发靠画布边缘，并有细碎青色边缘像素。眼部图截去了长发及衣服，不能作为完整可移动头像。

另一个项目四张 f 图仅用于理解剪影、少量大色块及四种镜头的用途；未采用橙发、花饰或具体五官。

## 三个轻量方向

1. 深海领航（采用）：保持宽水手领、宽袖、层次长发与尾巴；整理服装大色块，在胸口留独立浅色椭圆底座。
2. 静默研究员：同一身份和发型，收窄领口并降低青色装饰，偏克制。
3. 信号守望者：同一服装，只强调袖口与尾缘的连续青线，偏未来感。

## 制作原则

正面是服装与身份主参考。其他姿态以正面 v2 和各自 v1 作输入，由内置 imagegen 生成。扁平海军蓝、青蓝、浅海沫色；保留安静、聪明、略带孤独的气质。官方鲸鱼从官方 SVG 的独立 path 原样提取，保留 #4D6BFE，等比缩放置于空白底座，不交给生图模型重绘。原创鲸鱼另以独立 SVG 制作，并生成可替换版本。

每张另经过一轮内置 imagegen 边缘清理，原始生成与清理输出均保存。最终合成优先使用 cleaned 输出。少量发梢青色碎边仍存在，不应将透明与安全边距检查通过理解为已经达到逐像素无杂边；具体限制随 QA 报告交付。侧身为三分之二侧转，保留可读胸口徽章，不是严格 90 度侧面设定图。

## 使用与动画

根目录 deepseek_*_v2.png 为官方标识设计预览；deepseek_*_v2_original.png 为原创鲸鱼替代版。v2_sources 中 *_base.png 是透明无标识底图，*_logo_layer.png 是同画布透明标识层。logo_placement_v2.json 保存像素坐标、尺寸和归一化中心；compose_v2.py 可重建合成。

这些素材是姿态图，尚未完成分层绑定。头发、脸、身体、手臂、尾巴仍在底图内，尚未拆层或补齐被遮挡部分。制作骨骼动画前需沿色块边界拆分，并补画遮挡区。发丝的数量与衣服局部折线仍可能有生成差异，不应直接当作精确转面或逐帧动画。
