# 鲸鱼娘 v3：海沫白鲸鱼发饰

本轮按用户要求重新生图，把鲸鱼从胸口移到头发上，并统一配色、加入头饰随姿态变化的立体表现。v1、v2 与官方原始标识素材继续保留。

## 统一设计

- 单枚鲸鱼造型发夹位于人物左侧鬓发、侧鳍上方，正面看在画面右侧。
- 海沫白表面、午夜海军蓝厚边、少量海洋青倒角；去除与人物配色不协调的官方亮蓝色块。
- 鲸鱼造型以实际读取的官方 PNG 为参考，保留鲸头、腹部月牙负形与上翘双叶尾的识别特征。
- 使用硬边赛璐璐侧面阴影、发束遮挡与接触阴影表达厚度和固定关系；其他姿态以正面 v3 为头饰与衣服主参考。
- 胸口移除椭圆徽章，用小深蓝领结扣连接原来的领带与水手领。
- 继续保留层次青蓝长发、卷起呆毛、两侧鲸鳍、身后鲸尾与浅色脸部。

## 制作与交付

所有人物图使用内置 image_gen 重新生成，头饰直接融入画面，不在生成之后加贴鲸鱼 PNG。v3_sources 中保存原始生成输出和完整提示词。最终 deepseek_*_v3.png 在原生成透明通道之外添加 128px 透明安全边距，没有重新绘制或压平透明通道。总览和发饰近景另存为 JPG，只用于审阅，不是透明人物素材。

这些是二维绘画中表现厚度与透视的头饰，不是三维模型，也不是已经绑定的分层人物。头饰和头发目前在同一张生成图内；后续若需要独立旋转或摆动，需要沿头饰边缘拆层并补画其遮挡的头发。

## 品牌素材性质

头饰经过改色和立体造型改编，并由生图模型融入各姿态，因此不再是像素或矢量路径严格不变的官方 Logo 素材。官方原 SVG/PNG 与 v2 原标识图层仍保存在 v2_sources，可追溯参考来源。不能把生成头饰称为原样的官方标识。

此前读取的官方 guidelines.md 要求实际接入模型或 API，且不得任意修改品牌素材，并未明确覆盖独立社区二创 MV。用户本轮明确要求配色与造型改编，本套按二创概念效果制作；不表示已取得 DeepSeek 的公开使用许可。不要暗示本 MV 为 DeepSeek 官方制作、合作或授权作品。

## 动画使用

尽量以正面头饰为形状基准，在后期固定鲸头、负形、双尾与厚度的结构。生成姿态之间仍可能有小幅造型差异，不宜直接当作精确机械转面。角色外缘继承了一些 v1/v2 的细碎发梢像素，正式大幅放大或拆层绑定前仍需在实际 MV 背景上检查。
