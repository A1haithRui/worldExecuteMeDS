# 猫化鲸鱼图标

以本地官方 DeepSeek 鲸鱼 PNG 为参考，内置 image_gen 先制作完整形象，再用完整形象生成三部件图。

- cat_whale_complete.png：完整图，1254×1254，图标宽约画布 70%，洋红背景。
- cat_whale_parts.png：三个分离部件，左耳、右耳、猫尾，无身体，洋红背景。
- *_transparent.png：以上两图的透明底版本。
- left_ear.png / right_ear.png / cat_tail.png：由部件图直接裁出的独立透明素材，各加 32px 安全边距。
- sources/：未加工生图及实际提示词。
- qa_and_placements.json：尺寸、实际颜色、原图部件边界、居中缩放记录；不包含已验证的身体附着点。

成品经过确定性二色归一化，实际仅有 #4D6BFE 和 #FF00FF，没有渐变。透明版前景只有 #4D6BFE，透明度仅 0/255。为满足单色要求使用硬边阈值，因此不是抗锯齿矢量。

限制：完整鲸鱼是模型参照官方图重绘，未证明原标识轮廓逐像素不变。两张独立生成，部件形状接近但不能保证与完整图精确重合；实际耳朵约19%画幅、尾巴约34%，优先保留生成部件相对尺度。动画正式拼装前需按镜头调整附着点、缩放与遮挡。保留原有鲸鱼内部镂空，不新增五官。此为社区二创图形，不表示官方版本或授权。
