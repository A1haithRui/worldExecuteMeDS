⑤ 这一版按你的意见改了什么

1. 术语：world model → harness。启动页、标题栏、人格卡三处统一成 deepseek / harness。
理由：harness 说明"跑的是 dsh"，而 world model 是我们自己造的词，观众读不出来。
2. 启动行：power → 终端提示符。现在窗口底部是 ❯ dsh --boot，右下角状态 terminal ready。
原来的 "power" 想说的是电源线（配合歌词 Switch on the power line），但单看会读成 PowerShell，所以改成明确的终端行。
3. 界面装配：三处位置修正。"发消息，/ 调用指令" 现在在虚线框里垂直居中；"LAYOUT LOCKED" 移到窗口上方并加了分隔线，不再贴着框；header 里加了鲸鱼标志，和 deepseek / harness 组成完整的品牌锁排。
另外在空白的会话区加了一个很淡的鲸鱼水印（7% 不透明度），让"这是谁的窗口"更明确。
4. 人格卡：role 改成 assistant，并留出停顿。填写整体提前，最后一格填完后停留约 1.3 秒（原来只有 0.3 秒，看起来像闪过去）。
role 用 assistant 而不是 world model：header 已经写了 harness，再重复一次没必要；assistant 也正好是对话里的角色名。卡区内加了鲸鱼水印。
5. 最后一镜：照参考片重做。左侧栏有 New chat 和六条旧对话（Recents），中间是空的 New chat 与正中的鲸鱼标志，右侧人物暗淡在玻璃后面，右上角 harness · ready，底部 you / silent。
人物不透明度 48%、高度 1180px，填满画面右侧并出血；另外输入框会把这一句歌词逐字打出来（22 字/秒，正好在该句唱完时打完），空会话的提示语随输入淡出，发送按钮随之亮起。
